```
上传页支持批量投递（/admin）
```

## 正文（可直接粘贴）

### 概述

把 `/admin` 的单文件上传页换成批量上传工作台：选择文件夹后按目录层级自动折算成「学科分类 / 子目录」，与站内已有记录比对去重，排队批量上传。

仅前端改动。所有请求使用现有接口，未新增后端逻辑，未修改其它页面。

![批量上传页](https://github.com/pierrotto12138-code/upc-share/raw/feat/batch-upload/vue/tools/batch-page.png)

### 动机

现有上传入口一次只能提交一个文件。批量场景（一学期的课件、试卷、实验报告，上百个文件）下，重复填表与逐次点击的时间成本高于整理本身。

### 使用方式

1. 顶部选择学科分类（下拉支持模糊搜索，也可直接输入新建）。
2. 点「从文件夹导入」选择文件夹，或直接把文件夹拖进虚线框（会按层级递归展开，与前者同一条识别链路），也可以手动新建子目录后拖入文件。导入前会显示文件数、子目录数与目标学科分类，确认后落进工作台。
3. 底部「全部上传」。「只试运行」勾选后仅在日志列出计划，不发起任何上传；传完（或中途断掉）可以点「导出投递结果（CSV）」导一张带落点、状态、站内 id 与失败原因的表。

不清楚怎么摆文件夹的，点「从文件夹导入」右上角那颗「?」，会弹出完整的整理规范，可整段复制。

![整理规范弹层](https://github.com/pierrotto12138-code/upc-share/raw/feat/batch-upload/vue/tools/help-page.png)

### 实现要点

- **限速**：按 Nginx 规则（`6r/m`、`burst 3`、`并发 2`）在客户端排队，先放行 3 个请求，之后每 10.5 秒一个。429 退避 15s×次数，5xx 退避 4s×次数，最多重试 4 次。
- **子目录归属**：子目录必须挂在某个学科分类下。未选择分类时「新建子目录」禁用，并在按钮 `title` 中说明原因。
- **查重**：以站点为唯一真相，不做本地台账、不写 `localStorage`。同名同大小默认跳过；同名不同大小仅标记，不自动跳过。
- **已有资源过滤**：`/api/admin/files?status=pending` 返回全站待审核清单，不按学科分类过滤。前端取回后按 `category` + `sub_category` 二次过滤再合并，避免管理员在某个子目录列表中误删其它分类的文件。
- **删除确认**：删除站内文件需两次点击，4 秒内未确认自动取消。
- **权限**：「自动通过审核」仅在 `is_admin` 时渲染，且默认不勾选。服务端本身有鉴权，前端控制只影响入口可见性。
- **根目录常驻**：每个学科分类固定有一行「根目录」（`sub_category` 传空串），站内还没有根文件时也给，文件可以直接挂在分类下；这一行不可删。
- **删除只需一件事**：子目录行右侧是一颗两段式垃圾桶——第一次点只高亮并提示，4 秒内再点才真删。站内已有的子目录与根目录是禁用态（站点没有「目录」实体，删行删不掉任何服务端数据），说明里的「去已有资源删文件」只对管理员显示。
- **页面铺满**：`/admin` 按视口高度铺满，三栏吃掉剩余空间、队列条贴底；标题区压到 66px（站点默认给落地页的 64px 上 + 80px 下留白，用在工具页会把三栏挤到屏幕下半截）。
- **未登录提示**：未登录时顶部给一行「请先登录」并链到 `/login`；此前只会把 401 写进日志。
- **整理规范可复制**：`organizePrompt.js` 里的文案与 `logic.js` 的规则由同一条测试绑定（逐个比对扩展名白名单、检查是否写清 200MB / 两级 / 待审核 / 个人信息），改了代码忘了改文案会直接测试失败。

### 待确认（交给你定）

以下三项都是产品决策，**由你决定**——服务器在你手里，哪种做法对站点损耗最小、维护成本最低，你比我清楚。
我这边按下面的默认做法实现，三种切换的改动都不大，也不影响 PR 的主体结构：

1. **限速位置**：当前实现在客户端（令牌桶，burst 3 / 每 10.5 秒一个）。若倾向由服务端统一管理配额，可移除 `Pacer`，退化为串行上传 + 失败重试。
2. **`/admin` 页面归属**：当前直接替换原单文件上传页（单文件场景在批量视图中可用）。若需保留原页面，可改为 `?mode=batch` 共存或标签页切换。
3. **自动通过审核**：若审核必须人工完成，可整体移除该开关，批量上传结果全部留在待审核队列。

三项任选其一都能直接合并；你定了方向我再改，或者这版就先用默认值。

### 已知限制

- 子目录层级最多两级，更深的层级会合并为 `课件/第一章`，与站点落盘规则一致。
- 站内已有的子目录与「根目录」不能在左栏里删除：站点没有「目录」这个实体，只能去「已有资源」把里面的文件删完，那一行会随之消失。
- 单文件上限 200MB（站点本身允许 1GB），超限标记为跳过。
- 无多选批量删除，无上传队列持久化。
