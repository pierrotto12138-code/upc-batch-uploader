### v0.3.33 · 根目录不给改名（插件侧，跟站点页同步）

用户反馈线上网页版有三处不同步（叉掉学科分类后输入框还留着旧名字、切子目录后「已有资源」要重开一次、根目录能改名）。
前两条只出在 Vue 版（插件本来就是对的），第三条两边都有：`canRenameDir()` 没排除根目录——把「根目录」改个名，
文件会真的落到分类下一个叫「根目录」的子目录里。插件这里补上 `!dir.isRoot`，并导出给单测（32 项）。
Vue 版的三处修复只在本地分支 `fix/merged-page-bugs`，没有推上游、没有开新 PR。

### v0.3.29 · 手打全名也要带出站内已有子目录与「根目录」

用户报："打开课程如果有子目录的情况下好像不会显示根目录"。**先复现**：拿真账号在无头 Chrome 里只读地翻站内数据，找到几门"既有具名子目录、又有文件直接挂在分类根下"的课（ppt模板 / 信号与系统 / 大学物理），分别从下拉点选与手打全名两条路走一遍。结果：
**从下拉点选是对的**（左栏会列出「根目录」），**手打全名再回车/失焦是错的**——只算改名，站内子目录一个都不带，左栏只剩一个空「新子目录」，看起来就像"根目录没显示"。根因是 `startCourse` 只有一个调用方：`switchCourse`，而它只在 `how === "pick"`（点下拉）时触发。
改法：`commitTypedCourse()` 在回车与失焦两条路上都拿 `normalizeText` 去 `state.categories` 找同名，命中就按"选这门课"处理；判定仍用 `courseFocusName`，所以改名不会误伤，站内没有的名字仍然是新建。上游 Vue 版这条路本来就是对的（`commit()` 在 blur 时找精确命中并 `pickCourse`），不用动。
加断言时又踩到两个测试坑，都记进 AGENTS 第 8 节：① 上一步把输入框留着聚焦状态，下一步 `focus()` 不再触发 focus 事件，下拉压根没重画——必须先 `blur()` 再 `focus()`；② "换课"要挑的目标课如果恰好就是当前这门，只会算改名，断言永远红，得排除当前值。
验证：生产端到端 **55 项断言全过、站点无残留**（新增第 55 项：手打 C++ 回车 → 左栏出现「根目录」）；`node selftest.js` 30 项全绿。UI 没动，`preview.png` 沿用上一次的。

### v0.3.28 · 拖文件夹递归 + 结果导出 CSV（欠着的两个 P0）

**拖文件夹**：`drop` 事件里用 `webkitGetAsEntry()` 递归展开，拼出 `webkitRelativePath` 后
**直接复用「从文件夹导入」那条链路**（`flattenDropTree` 是纯函数、可单测）。
三条要点：① `webkitGetAsEntry()` 必须在 drop 的**同步阶段**取，回到异步全是 null；
② `readEntries()` 一次最多给 100 条，必须循环读到空数组为止，否则大文件夹被悄悄截断；
③ 拖进来的**根目录名保留成路径第一段**，这样 `webkitRelativePath` 与 `input[webkitdirectory]`
给出来的形状一模一样，折算结果自然也一样——验收就是"拖与选完全一致"。
含文件夹的拖拽走导入识别（弹"看得见规模"的确认），只拖文件才塞进当前子目录。

**结果导出**：`exportCsv(rows)` 也是纯函数，列是 `relPath,category,sub_category,status,id,error`，
**UTF-8 BOM + CRLF**（Excel 双击不乱码），逗号/引号/换行按 CSV 规则转义。
底部队列多了一颗「导出结果」（次级档盒子），没文件时禁用。

顺带把用户这轮的另一句做了：**"下面那些字体也规范一下"**。量出来面板里有 9 种字号、4 种字重，
现在收成四档：**20（页面标题）/ 15（区块与主操作）/ 13（正文）/ 12（辅助）**，字重只留 400/500/600；
符号（×、⋯）走 15px，「?」徽标 12px/600 在 20px 圆里。规格写进 `docs/design.md` §20/§21，
并且有断言守着：插件 `smoke.mjs` 4b5 会枚举面板里所有渲染文本的字号，出现第五种就红；
Vue 版 `ui-check.mjs` 22 同理。

**两个新坑（都写进了 AGENTS §8）**：`Blob.text()` 解码时会吃掉开头的 BOM，量 BOM 必须按字节看；
读 `folderConfirm.hidden` 要在点「取消」之前读，之后永远是 hidden。

验证：插件生产端到端 **54 项断言全过、站点无残留**（含拖入三层文件夹 → 弹确认 → 取消后工作台零改动、
导出 CSV 按字节核对 BOM/表头/行数）；`node selftest.js` **30 项全绿**；
Vue 版 `ui-check` **24/24**、`node --test` **30 条**、`vite build` 通过。
